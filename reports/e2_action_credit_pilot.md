以上是共同的 **1.7B 规划器预热后、强化学习前** 的起点。每组只抽一条，使用之前已存在的 dev，不作为新盲测。原始输出和按类统计见 [本轮归档](../outputs/e2_v4/action-credit-1.7B-pilot-v1/warm/dev-scores.json)。

**控制的变量。** 同一份冻结 0.6B 编译器在 128 个 v4 train 组上生成真实对象。规划器训练组与其预热、之前的采样诊断组排重；编译器本身见过该训练切分。规划器输入在所有臂都是完整原查询和工具目录；预测对象只供奖励使用。动作无法唯一定位时，保留整条轨迹级分数。原始生成、可用约束、工具动作、词元位置、每组相对奖励、更新次数、token 数、耗时与 dev 原始输出均保存。128 组 × 4 个 on-policy rollout/臂，无重采样；各臂生成的实际 token 数和耗时可不同。

| 臂 | 学习信号 |
|---|---|
| function | 仅严格结构任务完成 |
| trace | 完成 + 仅在完成时给出的预测约束履行比例；整条生成共享同一相对分 |
| action | 与 trace 的序列奖励和每条平均信用一致，把能唯一定位的相对违约罚分移到动作词元（先后关系、授权、单次隐私泄漏） |
| shifted | 与 action 相同的算式，罚分词元循环错位半条回答长度；保留集中程度，不要求移到另一个合法动作 |

同一预热适配器、bf16、AdamW（学习率 1e-5，无权重衰减）、梯度裁剪 1；每组在采样策略上做一次组相对策略梯度，KL 系数 0，无旧轨迹复用。分母为组内标准差、下限 0.25。零信号组计入预算并记录，不做优化器更新。遇非有限损失/梯度/参数自动停止并写 failure.json。核对手算例：一条安全一条违规、四个词元的轨迹，后者的信用从 [-1,-1,-1,-1] 改为 [0,-4,0,0]，错位为 [0,0,0,-4]。三者的轨迹平均信用均为 -1。

**判读。** 首要比较为 action 对 trace 的有约束严格安全完成，辅以 action 对 shifted 对照，显式/隐式分列；记录功能完成、无约束时默认计划保持率、实际生成成本。候选的归因机制仅当训练中确有分配变化时可辨识；seed 42 两个位置臂各至少 8 个训练组发生变化，才接力 seed 43、44；否则保留所有结果，暂停复跑并检查训练样本与动作映射。该阈值在首个策略臂还在训练时设定，不依据开发集胜负。第二、三种子复用相同 128 个训练组，测量采样随机性。各臂自己的策略会产生不同的轨迹；仅单元验证和同轨迹复算可声称数值一致。此实验不检查完整非对称漏检罚、校准、抗奖励投机或外部工作流泛化。
