四臂在 dev、tool_ho、struct_ho 的 N 版 false-alarm 均为 0。tpl_ho 上分别为：A1 0/350（0%）、A2 18/350（5.14%）、A3 71/350（20.29%）、A4 5/350（1.43%）。因此 A3 的模板留出 N 误报明显；不能只看受约束 faithful 宣称消融保持了三态拒判行为。

## 可以支持与不能支持的结论

1. **A3 是最清晰的单 seed 机制信号。** 把显式与隐式折叠后，工具和结构留出 faithful 分别低 24 和 29 个百分点，配对区间不跨零；N 模板误报为 20.29%。这与三态信号有用的假设一致，但 A3 同时改变 query_state、constraint.state、schema、提示和 target；单 seed 且无效输出率约 24–25%。因此只能写成受控单 seed 消融观察，不能写成已经隔离证明“三态导致”收益。
2. **A2 也在 OOD 切分上变差，但因果解释有限。** tool/struct faithful 低 14.43/36.29pp，同时无效输出率升至 27.81/25.24%。结果说明此训练臂在该协议下不稳，不能把全部下降归因于“证据字段的语义价值”。
3. **A4 推翻“每个输出字段都不可缺”的宽泛表述。** 去 scope 后，执行不依赖该字段的管线没有下降：工具留出与基线相近，结构留出高 7pp；剩余字段记录分数也较高。这是单 seed 的探索性反例，可能包含训练方差和输出长度效应，不能声称去 scope 因果提升；但它足以要求论文删除“scope 对执行成功必要”的断言。scope 的价值只能由记录质量/下游实际消费它的另一个任务来证明。
4. **A1 与 A2/A3 的 OOD 降幅伴随有效性/格式问题。** A1/A2/A3 工具与结构留出无效输出率范围为 12.29–27.81%，故需要同时看 valid-faithful，不能只报宽松旧 faithful。A1 是字符串序列化对照，不是“无类型”或“无约束”对照。
5. 四个消融在同一 seed 下训练，仍有训练 target token 数差异：A1/A2/A3/A4 分别 0.894M/1.868M/2.521M/2.169M；训练 prompt token 分别 24.66M/25.67M/25.77M/24.30M。均为 9,000 更新不等于匹配 FLOPs、监督 token 或墙钟成本。各臂 `elapsed_s` 包括初始化与评测，正文成本比较应使用原始训练日志及明确定义的时间字段。
