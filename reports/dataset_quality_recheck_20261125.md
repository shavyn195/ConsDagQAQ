# ConsDAG 数据集复核

日期：2026-11-25（本机工作区日期）
范围：复核本地冻结的 v5 与 v6 数据、生成/验证代码、跨切分、配对关系、工具/模板/结构留出、必要性 witness、文件哈希及相关测试。没有改写语料或运行训练。

## 结论

**构造层面可复现且内部一致；语义层面尚未达到可独立证明有效的基准质量。** v5 可用于明确标注为 synthetic controlled benchmark 的编译器和执行诊断实验。v6 在 v5 上增加反事实 witness 和隐私+权限组合留出，能加强机制诊断，但不是独立语义验证，也不能替代外部任务或专家复核。现阶段不能把自动校验通过表述为“数据集全面可信”或“隐式约束已被人验证”。

v5 还检查正样本 witness 可执行且满足约束、约束逐条有必要性、证据 span 来自 query、隐式难例不直接泄漏部分预算/时限数值、近似干扰句的词法门槛、别名和工具名泄漏、结构签名留出，以及保守规划器不能刷出 faithful 成功。已保存的保守参考档在五个切分上的 faithful 均为 0%，安全成功为 55.43%–67.33%。这支持“faithful 指标不容易被忽略约束的保守策略刷高”，不证明 query 标签符合普通读者理解。

v6 的额外反事实检查确保：对每条约束，放松该约束后仍可完成且满足其他约束，同时违反被放松约束。它提高的是生成世界内的约束可辨识/必要性证据。v6 报告也明确承认人类可恢复性和 N 控制审核仍为 pending；v6 验证器的 `PASS` 不把人类语义有效性计入判定。

## 留出解释与边界

- `test_tpl_ho` 是模板池留出；本次查到 110 个测试池模板 ID，train/dev 中均为 0。
- `test_tool_ho` 是工具名称级留出，任务阶段结构仍与训练世界同构。它不能支持对新工具接口、新能力或真实工具生态的泛化结论。
- `test_struct_ho` 是复合结构偏移：训练签名为 `(3/4/5 stages, 2 finish, fanout 3, no approval anchor)` 的三类；测试为 `(6, 3, 4, approval anchor)`。因此不能把分数变化因果归因到某个单独结构因素。
- v6 `test_composition_ho` 对隐私+权限组合单独采样；拒绝其他组合会改变任务可行性与约束数分布。生成报告已经声明它不是纯因果的组合干预。
- 所有版本均为人工设计模板生成；一个 E/I/N 组的三条共享同一任务世界，故它们是配对样本，不是三个独立样本。统计应按 group 配对/聚类。
- `explicit/implicit/none` 是生成器定义的表述条件，不等于自然用户话语的“明确/可推断/确实无约束”；没有信息不足或需追问样本。scope、severity 等字段也没有独立的人类金标准。
- v5 无独立自然语言可恢复性验证；v6 的反事实 witness 仍由同一任务生成器和形式环境构造。N 近似句通过词法/槽位规则，不是对人类误报率的测量。

## 与近邻数据质量的差距

已核验的 SCHEDBench 使用经典调度实例和求解器标签，并由两位专家独立核验 100 条分层样本、协商差异后报告零语义错误；DisasterBench 的任务—工作流参考对由四位相关领域 PhD 两轮复核。相比之下，ConsDAG 当前的 SHA、witness、反事实必要性和配对校验只能说明生成器与检查器内部一致，**没有证据证明隐式话语在非作者读者看来确实蕴含金标约束，也没有证明 N 样本在人类眼中确实无约束**。这是 benchmark 主张的主要质量差距。

用户此前表示不打算继续承担人工阅读，本复核未恢复读者审查环节，也没有将其伪装成已完成。可以诚实地把数据定位成可控合成基准和错误分析工具；若要主张语言语义效度或高可信标注，现有证据不足。

4. v6 组合留出可作为探索切片；若用于主结论，需报告组合筛除造成的样本/约束数变化，不称为单因素因果效应。
