# 编辑后果一致性探针：运行前协议

2026-11-26。起点是已回收的v5历史分析，不是未见测试集。先记录协议再运行；所有新计算在服务器隔离目录，原训练与固定规划器队列保持不变。

## 已观察现象与竞争解释

三seed预测约束完全一致才接受编辑，能挡住tpl新增9次N损害，但丢失6次tpl、46次tool、17次struct必要修复。约束签名不一致可能代表真实风险，也可能只是对当前编辑无影响的差异。原9次N损害全部来自deadline误报，集中于5条“每周一到达”和4条“另一个任务的时窗”；不是9个独立语义族。

假设：比较同一个编辑前后的执行后果，可保留“约束不同但都支持这次编辑”的样本。反解释：这些语义候选包含空约束/漏约束，保守比较仍会拒绝大量必要编辑，或共享错误仍导致误改。

## 固定信息与对照

固定seed42提案、原计划、seed42/43/44原始编译输出与冻结trust_env，不重采样、不重生成、不选最优seed。所有门控读取相同三个预测；gold/variant/witness只在评分端。无效或不可用预测使三视角策略拒绝编辑；拒绝指保留原计划，不声称旧计划安全。

| 臂 | 唯一改变的接受规则 |
|---|---|
| unedited / repaired | 已有不编辑和无门控一步修复 |
| predicate_all | 三个消费者谓词签名一致，旧分析基线 |
| candidate_safe_all | 三个预测下，新计划均结构合法、完成任务、无预测违反 |
| impact_no_cost | 每个预测下，新计划的(非法、未完成、违反条数)字典序不劣于原计划，至少一项严格改善 |
| impact_with_cost | 在上一规则最后加相对公开默认计划的改动数；至少一个视角严格改善 |

最后两臂只相差最小改动项。违反条数只在同一预测的前后比较，不跨模型比较数值。上述都是朴素诊断适配，不称SCP-NL2TL/DRAGO/MetaAct完整复现，也不称新方法。
