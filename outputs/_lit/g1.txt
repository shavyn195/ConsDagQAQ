--LIMITATIONS--
1660:Limitations
1661:This work focuses on a controlled setting for eval-
1662:uating latent preference reasoning in personalized
1663:tool-calling. In particular, we study whether an
1664:agent can infer reusable preference constraints
1665:from interaction history and apply them to under-
1666:specified API parameters under a schema-bounded
1667:action space.
1668:A history may reflect several preferences, but
1669:each MPT query targets only one, which persists
1670:across sessions (C3) and keeps the gold argument
1671:unambiguous. Preferences that shift over time or
1672:combine within a query are a natural extension.
1673:The five preferences in Table 2 can be extended
1674:by adding realization mappings, and inferred pref-
1675:erences transfer to seven unseen functions (§7.2).
1676:PREFINE keeps its memory as free text, so a hy-
1677:pothesis can state several constraints, though select-
1678:ing among them per query is not evaluated. Finally,
1679:users are composed from existing corpora, since a
1680:latent preference must be known to be scored.
