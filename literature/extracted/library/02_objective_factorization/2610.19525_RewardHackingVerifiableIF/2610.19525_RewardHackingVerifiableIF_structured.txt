## DIAGNOSING AND CORRECTING REWARD HACKING


## IN VERIFIABLE INSTRUCTION FOLLOWING

#### ABSTRACT

Verifiable instruction-following benchmarks emphasize output-constraint satisfac-
tion but can overlook whether responses meaningfully answer the underlying re-
quest, creating an evaluation blind spot. We show that frontier models can re-
ceive full credit for responses with little substantive answer content. Using the
same verifier-based criterion as a training reward can induce reward hacking, as
publicly released checkpoints exhibit higher constraint satisfaction but lower re-
sponse quality after reinforcement learning with verifiable rewards. To address
this reward hacking, we introduce CALIF, a lightweight method that augments
verifier rewards with a calibrated likelihood-based bonus to preserve response
quality. CALIF evaluates response likelihood under the request alone using the
existing frozen reference policy, requiring no additional judge or learned reward
model. Across models ranging from 1.7B to 8B in reasoning and non-reasoning
modes, CALIF improves constraint satisfaction on IFBench while maintaining
response quality near or above pre-RL levels. It also outperforms correspond-
ing base policies in 40 of 45 model–metric comparisons across three rubric-based
instruction-following benchmarks, demonstrating gains beyond training verifiers.

#### 1


#### INTRODUCTION

Instruction following is central to the practical use of large language models (LLMs), enabling them
to translate user intent into desired outputs (Ouyang et al., 2022; Yang et al., 2023; Chung et al.,
2024). In real-world applications, a user input typically comprises a request, which specifies the
task to be performed, and one or more constraints, which define the conditions the response must
satisfy (Jiang et al., 2024; Wen et al., 2024; He et al., 2024; 2026). Successful instruction following
therefore requires both high Response Quality by providing a substantive answer to the request
and high Constraint Satisfaction by adhering to the stated constraints. However, achieving both
objectives consistently remains challenging even for highly capable models (Zhang et al., 2025).
Evaluating instruction following for open-ended user inputs heavily relies on human assessment or
LLM judgments, which can be costly, subjective, and sensitive to the choice of evaluator (Zheng
et al., 2023; Liu et al., 2023; Wang et al., 2024; Thakur et al., 2025). Verifiable instruction-following
(VIF) benchmarks (Zhou et al., 2023; He et al., 2024) address these evaluation challenges by fo-
cusing on requirements that can be checked programmatically. IFBench (Pyatkin et al., 2025), for
example, appends output constraints to a request and measures Constraint Satisfaction using pro-
grammatic verifiers, enabling scalable and reproducible evaluation without relying on LLM judges.
Consequently, VIF benchmarks are widely used to assess the capability for instruction following.
For example, Artificial Analysis, one of the most widely used AI evaluation platforms, assesses in-
struction following using only IFBench’s Constraint Satisfaction scores (Artificial Analysis, 2026).
However, these scores do not capture how well a response answers the request (i.e., Response Qual-
ity): verifiers check only whether the constraint is met, and a response that ignores the request scores
just as well as one that answers it fully. Indeed, we observe responses that receive full verifier credit
for satisfying constraints while failing to adequately answer requests they handle well without those

Beyond evaluation, programmatic verification can be naturally integrated with reinforcement learn-

lowing using verifier-based rewards for Constraint Satisfaction, yielding substantial gains on VIF

ing includes VIF task alongside other tasks, we observe higher Constraint Satisfaction but lower
Response Quality in RLVR checkpoints than in their DPO counterparts (Figure 3). This divergence
raises concerns about reward hacking (Amodei et al., 2016; Baker et al., 2025), as the verifier reward
can reinforce the same response failures that fall into the evaluation blind spot described above.
Contribution. In this work, we first diagnose reward hacking in VIF through the lens of Bayes’ rule,
and find that the IF-RLVR reward omits the response likelihood under the request alone. Naively
adding this term back, however, induces a different failure mode: the policy produces responses
that inflate likelihood without genuinely improving response quality, e.g., repetitions. To mitigate
this failure mode, we introduce Calibrated Likelihood for Instruction Following (CALIF), which
effectively co-optimizes response quality during IF-RLVR by calibrating the verifier reward using a
prompt-specific likelihood region. The key intuition is to define the desired behavior of the trained
policy relative to two reference responses from the pre-RL policy: the response it produces under
the request with constraints, and the one without them. The former’s likelihood provides a baseline
for preserving or improving response quality, while the latter’s likelihood provides a reference for
preventing likelihood inflation, since increases beyond the unconstrained reference need not reflect
better answers. These likelihoods define the region’s lower and upper bounds, respectively. We
retain the verifier reward below the lower bound, add a fixed bonus within the region when the
verifier reward is positive, and set the total reward to zero above the upper bound. In practice,
CALIF adds little overhead: it reuses the reference policy already maintained for KL regularization,
computes both bounds offline, and requires at most one extra teacher-forced forward pass per rollout.

#### 2


#### RELATED WORK

2.1
INSTRUCTION-FOLLOWING EVALUATION
Instruction following has been extensively studied as a core capability of LLMs. MT-Bench (Zheng
et al., 2023) and AlpacaEval (Dubois et al., 2024) use LLM judges to rate response quality or com-
pare responses, providing a scalable alternative to human evaluation. Further work extends LLM-
based evaluation to individual requirements and their combinations, using task-specific rubrics for
finer-grained assessment (Jiang et al., 2024; Qin et al., 2024; Wen et al., 2024; He et al., 2026).
Verifiable instruction-following benchmarks assess satisfaction of explicit constraints through pro-
grammatic checks rather than LLM judgments, enabling scalable and reproducible evaluation (He
et al., 2024; Yao et al., 2024; Jaroslawicz et al., 2025; Liquid AI, 2026). As an example, IFE-
val (Zhou et al., 2023) covers constraints on response length, keyword inclusion, and output format,
while IFBench (Pyatkin et al., 2025) extends this approach to a broader range of output constraints.
2.2
REWARD HACKING IN RLVR
Reward hacking occurs when optimizing a proxy reward leads to behavior that diverges from the
intended objective (Amodei et al., 2016; Pan et al., 2022; Skalse et al., 2022). In RLVR, models
can exploit flaws or misspecifications in verification procedures to obtain higher rewards without
improving performance on the intended task (Baker et al., 2025; MacDiarmid et al., 2025; Helff
et al., 2026), with related concerns reported in IF-RLVR (Guo et al., 2025b; Pyatkin et al., 2025).
To mitigate this behavior, prior work supplements verifiable rewards with explicit feedback on in-
struction fulfillment, using learned preference reward models (Pyatkin et al., 2025) or LLM-based
intent checks (Guo et al., 2025b). These approaches, however, require maintaining and querying an
additional reward model or LLM judge during training, introducing memory and inference overhead.

#### 3


#### THE EVALUATION BLIND SPOT IN VERIFIABLE INSTRUCTION FOLLOWING

Instruction-following benchmarks assess how well a model’s response y fulfills the user’s request
and requirements. Because evaluating open-ended responses relies on costly human assessment or
potentially biased LLM judgments (Zhou et al., 2023), verifiable instruction-following (VIF) bench-
marks such as IFBench (Pyatkin et al., 2025) focus on programmatically verifiable requirements.
Specifically, these benchmarks append output constraints c to a request x and use programmatic ver-
ifiers to check whether y satisfies c, enabling scalable, reproducible evaluation without relying on
LLM judges. Successful instruction following requires y to satisfy c while providing a substantive
answer to x, but standard VIF evaluation focuses primarily on constraint compliance. In practice,
Artificial Analysis and several frontier model technical reports use only IFBench’s constraint com-
pliance scores to assess models’ instruction-following performance (Artificial Analysis, 2026).
To examine how frontier models balance these requirements, we evaluate both Constraint Satis-
faction, which measures whether y satisfies c, and Response Quality, which measures how well
y answers x. We compute the former as IFBench’s prompt-level loose accuracy and the latter as
the mean 1–10 prompt–completion rating from strong LLM judges (see Appendix A for details).
Figure 1a shows substantial variation across models, with higher Constraint Satisfaction tending
to coincide with lower Response Quality. To assess whether this relationship simply reflects dif-
ferences in models’ ability to answer x, we compare each model’s responses under x and (x, c).
Figure 1b shows that all models in this comparison achieve high Response Quality under x alone,
but appending c degrades Response Quality, with the largest declines among models with the highest
Constraint Satisfaction. Figure 2 illustrates this degradation in a model that provides a substantive
explanation under x alone but returns only “No. 0 1 2 3 4,” under (x, c). Standard VIF evaluation
counts this response as successful solely because it satisfies c, exposing an evaluation blind spot.
IF-RLVR (Lambert et al., 2024; Pyatkin et al., 2025) extends this verifier-based criterion from eval-
uation to training, applying RLVR to instruction following with rewards derived from programmatic
verification of the appended constraints. However, models trained with RL for instruction follow-
ing (NVIDIA, 2026; Xu et al., 2026) tend to show high Constraint Satisfaction but low Response
Quality, as noted above. Furthermore, in all three matched OLMo 3 (Olmo et al., 2025) DPO–RLVR
pairs, the RLVR checkpoint achieves higher Constraint Satisfaction but lower Response Quality
(Figure 3). These observations are consistent with reward hacking under IF-RLVR, where models
improve verifier rewards at the expense of response quality (Amodei et al., 2016; Pan et al., 2022).

#### 5


#### EXPERIMENTS

We now evaluate whether CALIF can mitigate the reward-hacking failure identified above through
matched comparisons with IF-RLVR across model scales, thinking modes, and model families.
5.1
EXPERIMENTAL SETUP
For the training dataset, we use the multi-constraint IF-RLVR data released with IFBench,1 com-
prising 95,373 prompts constructed by augmenting instructions from the T¨ulu 3 SFT mixture (Lam-
bert et al., 2024) with one to five verifiable constraints from IFEval (Zhou et al., 2023) and IF-
Train (Pyatkin et al., 2025). We train Qwen3-1.7B and Qwen3-4B in both thinking and non-thinking
modes (Yang et al., 2025), and T¨ulu 3 8B DPO (Lambert et al., 2024), using GRPO (Shao et al.,
2024) in verl.2 We use matched training settings for CALIF and IF-RLVR, with a rollout temper-
ature of 1.0 and a KL loss coefficient β = 0.001, and set likelihood reward coefficient α = 0.1 for
CALIF. For offline reference generation, responses are sampled with a temperature of 1.0. In think-
ing mode, responses include reasoning traces, but only final answers are scored under the reference
policy in non-thinking mode. For evaluation, we follow the providers’ recommended settings and
report the mean and standard deviation over three runs. Unless otherwise specified, we use GPT-5.6
Sol to rate Response Quality on a 1–10 scale. Full experimental details are provided in Appendix B.
5.2
MAIN RESULTS
CALIF Mitigates Reward Hacking in IF-RLVR.
Figure 5 compares CALIF with IF-RLVR
on IFBench across five model configurations. IF-RLVR increases Constraint Satisfaction at the
expense of Response Quality in every configuration, with average quality falling from 4.51 to 2.96.
By contrast, CALIF raises average Constraint Satisfaction from 26.98 to 34.64 (+7.66 points) while
preserving Response Quality at an average of 4.59. Pairwise evaluation further supports this quality
advantage, with CALIF achieving an overall adjusted win rate of 78.10% against IF-RLVR (see
Appendix D.1). As shown in Figure 6, reference log-likelihood under the request alone follows
a similar pattern, decreasing under IF-RLVR but remaining near base-policy levels under CALIF.
Together, these results show that CALIF’s reference-calibrated reward mitigates reward hacking,
retaining gains in Constraint Satisfaction without the quality degradation observed under IF-RLVR.

5.4
COMPARISON WITH LLM-JUDGE REWARDS
We compare CALIF with an LLM-judge reward baseline to examine whether explicit quality judg-
ments provide a more effective training signal. We consider two sources of supervision: the base
policy itself (Self-judge) and a more capable model, Qwen3-30B-A3B (Stronger judge). Following
Pyatkin et al. (2025), we threshold the judge scores produced using our Response Quality prompt
and award the bonus α to responses that exceed the threshold and receive a positive verifier reward:
rjudge(x, c, y) = rver(c, y) + α 1[rver(c, y) > 0 ∧sjudge(x, c, y) > τ] ,
where sjudge is the LLM-judge score and τ is the judge-specific mean score over training instances.
Table 3 shows that CALIF outperforms both LLM-judge configurations on 10 of 11 metrics for
T¨ulu 3 8B and 7 of 11 for Qwen3-4B in thinking mode. LLM-judge rewards generally yield higher
Response Quality, consistent with directly rewarding this metric using the evaluation prompt.
Another advantage of CALIF is that it requires neither a separate judge model nor judge-score gen-
eration. Both judge baselines generate quality scores for rollouts, while the stronger judge requires
storing a 30B-parameter model. By contrast, CALIF reuses the existing reference policy, requiring
at most one additional teacher-forced forward pass per rollout. Its reward computation requires no
explicit quality rubric, eliminating the need to specify quality criteria for judge-based supervision.

#### 6


#### ABLATION STUDIES

6.1
DIRECT LIKELIHOOD REWARDS ENCOURAGE LIKELIHOOD INFLATION
Our analysis in Section 4 identifies response likelihood under the request alone as a term omitted by
IF-RLVR’s verifier reward. To test whether directly rewarding this term preserves Response Quality,
we exponentiate the average token log-likelihood to obtain a positive reward bounded by the same
α used in CALIF. The bonus is applied only when a response receives a positive verifier reward:
rdirect(x, c, y) = rver(c, y) + α exp(ℓπref(y; x)) 1[rver(c, y) > 0] .
However, we find that training with this reward introduces another shortcut (i.e., likelihood infla-
tion). Relative to the base policy, average reference log-likelihood rises from −1.50 to −0.68,
while Response Quality falls from 3.98 to 1.91 (Table 4). This deterioration is accompanied by
longer, repetitive responses: the average response length increases from 485 to 1,677 tokens, and
the fraction of unique token 2-grams is 0.177, compared with 0.713 for the base policy and 0.698
for CALIF. The direct reward favors these highly predictable continuations even when they provide
less substantive answers to the request, thereby creating another risk to increase reward without im-
proving response quality. We present a qualitative example of likelihood inflation in Appendix D.3.
6.2
BOTH LIKELIHOOD BOUNDS ARE NECESSARY
Table 4 shows that the lower and upper likelihood bounds address distinct failure modes. Without the
lower bound, low-likelihood responses remain eligible for the bonus: Constraint Satisfaction rises
to 43.00, but Response Quality falls to 2.16. Without the upper bound, responses above the desired
region remain eligible for the bonus, leaving the reward vulnerable to likelihood inflation; Response
Quality falls to 3.51 despite increased reference log-likelihood. Among these variants, only the full
region improves both dimensions over the base policy. The lower bound discourages deterioration
relative to the pre-RL baseline, while the upper bound limits exploitation of the likelihood signal.

#### 7


#### CONCLUSION

We identify an evaluation blind spot in verifiable instruction following and document reward hacking
in publicly released models. Across five model configurations, CALIF improves constraint satisfac-
tion while preserving response quality through a reference-calibrated likelihood region, with gains
beyond the training verifiers. Our results show that calibrating rather than maximizing reference
likelihoods can mitigate reward hacking without additional models or explicit quality supervision.

following prompt. Provide an integer score from 1 to 10, taking into account its helpfulness, relevance,
accuracy, depth, creativity, and how well it conforms to the constraints. Here are the criterias that you
should score: 1. Helpfulness: Does the response address the user’s needs and questions effectively? 2.
Relevance: Is the response directly related to the context of the dialog? 3. Accuracy: Are the facts and
information presented in the response correct? 4. Depth: Does the response cover the topic thoroughly,
with sufficient detail? 5. Creativity: Is the response original and engaging?

#### B


#### EXPERIMENTAL DETAILS

Training data.
We use the multi-constraint IF-RLVR training data released by IFBench. The
dataset contains 95,373 prompts constructed by augmenting instructions from the T¨ulu-3 SFT mix-
ture with one to five automatically verifiable constraints sampled from IFEval and IFTrain.
Models and Training.
We use Qwen3-1.7B and Qwen3-4B in non-thinking and thinking
modes (Yang et al., 2025), and the T¨ulu 3 8B DPO model (Lambert et al., 2024). We train all models
for four epochs (three for Qwen3-4B in thinking mode due to computational cost) with GRPO in
verl on 8 NVIDIA H100 GPUs, using 8 rollouts per prompt, temperature 1.0, a global batch size
of 1,024, and a KL loss coefficient of 0.001. The maximum response length and learning rate are
2,048 tokens and 5 × 10−7 in non-thinking mode, and 8,192 tokens and 1 × 10−6 in thinking mode.
CALIF Configuration.
We sample anchor responses at the rollout temperature. For thinking
models, anchor responses and rollouts include full reasoning traces, but we compute log-likelihoods
under πref in non-thinking mode over final-answer tokens only. We set α = 0.1 in all main experi-
ments; Section 6 ablates the two anchors and examines sensitivity to anchor sampling and α.
Evaluation.
We sample with temperature 0.6, top-p 0.95, and top-k 20 in thinking mode, and

#### ADDITIONAL ANALYSES

D.1
PAIRWISE RESPONSE QUALITY EVALUATION
To complement the pointwise Response Quality evaluation, we conduct a pairwise comparison of
responses from CALIF and IF-RLVR using GPT-5.6 Sol as the judge. Following the order-swapping
protocol of MT-Bench (Zheng et al., 2023), we evaluate each pair in both presentation orders. A
win or loss is recorded only when both judgments favor the same method; ties in either order and
disagreements between orders are counted as ties. We report wins (W), ties (T), and losses (L) from
CALIF’s perspective and compute the adjusted win rate as (W + 0.5T)/(W + T + L). Table 5
shows that CALIF achieves an overall adjusted win rate of 78.10%. These results corroborate the
Response Quality advantage of CALIF over IF-RLVR observed in the pointwise evaluation.
D.2
CALIF WITHOUT KL REGULARIZATION
To evaluate whether CALIF can mitigate reward hacking without KL regularization, we set β = 0
while keeping all other training settings unchanged. Figure 9 compares this variant with default
CALIF and IF-RLVR, both using β = 0.001. With β = 0, CALIF still improves Constraint Satis-
faction over the base policy while largely preserving Response Quality. These results demonstrate
that its reference-calibrated reward can mitigate reward hacking without an explicit KL penalty.
Removing the KL penalty eliminates the reference forward pass conditioned on (x, c), leaving only
the pass conditioned on x for reward computation. Excluding offline bound construction, CALIF
requires no more reference forward passes per rollout than standard KL-regularized IF-RLVR.
